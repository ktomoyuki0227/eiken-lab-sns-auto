# Claude in Chrome 操作ガイド - TRE X予約投稿（TOEICクイズシリーズ）

最終更新：2026-05-21
用途：Claude in Chrome を使って X の予約投稿UIを操作するための手順書（クイズシリーズ版）。

---

## 使用前の準備

1. PCブラウザ（Chrome）でXにログインした状態にする
2. x.com を開き、新規投稿できる状態にしておく
3. Chrome の拡張機能管理（chrome://extensions）を開き、**Claude in Chrome 以外をすべて無効化**する
4. Claude in Chrome のサイドバーを起動する
5. 下記「プロンプトの使い方」の手順でプロンプトを貼り付けて送信する

---

## プロンプトの使い方

実際のプロンプト本文は `.txt` ファイルに格納されている。**メモ帳で開いてコピペすること**（マークダウンエディタは改行が崩れるため不可）。

| ファイル | 用途 | 件数 |
|---------|------|------|
| `prompt-quiz-test.txt` | テスト用（動作確認） | No.1〜3（3件） |
| `prompt-quiz-main-1.txt` | 本番用・前半 | No.4〜33（30件） |
| `prompt-quiz-main-2.txt` | 本番用・後半 | No.34〜60（27件） |

各ファイルに **投稿文（クイズ）とリプライ文（正解＋解説＋CTA）がセットで含まれている**。
X のスレッド機能（「＋」ボタン）を使い、1回の操作で投稿文とリプライ文を同時に予約設定できる。

### 手順

1. 使用するファイルをメモ帳（Notepad）で開く
2. Ctrl+A → Ctrl+C でコピー
3. Claude in Chrome のテキストボックスに貼り付けて送信

### 分割の理由

1回あたり **30件以下**に分割して送ること（コンテキスト・処理時間・クレジットの観点）。

---

## プロンプトファイルの改行ルール

`.txt` ファイル内の投稿文では「空行」を **`　`（全角スペース1字のみの行）**で表現している。
Claude in Chrome が投稿文をテキストボックスに入力する際は、`　` を削除して空行（Enterキー2回）に変換するよう指示が入っている。

---

## クイズ投稿フォーマットの確認

### メインツイート（予約投稿）

各投稿は以下の構成になっている：

```
5秒で解けたらTOEIC○○点。
　
[英文（空欄 _____ あり）]
　
(A) [選択肢A]
(B) [選択肢B]
(C) [選択肢C]
(D) [選択肢D]
　
答えはリプ👇
　
#TOEIC #英語学習 #勉強垢
```

TREの通常投稿（解法系・スコアアップ系）と異なり、URLなし。フォーマットが変わっているが操作手順は同じ。

---

### 返信ツイート（メインツイート公開後に手動投稿）

メインツイートが公開されたら、そのツイートへの返信として以下の「返信文」を投稿する。
返信文は `x-posts-quiz.csv` の **返信文** 列に全60件分が記載されている。

**返信文のフォーマット：**

```
正解は([選択肢記号]) [正解テキスト]！

[解説（正解の理由・不正解の理由）]

無料相談・無料レッスンはこちら👇
https://the-rep-english.jp
```

**文字数：** 約130〜180 / 280（余裕あり）

**手順：**
1. 公開済みのクイズツイートを開く
2. 返信（リプライ）ボタンをクリック
3. `x-posts-quiz.csv` の該当 No. の「返信文」列をコピーして貼り付け
4. 投稿する（返信は予約投稿不要・即時投稿でOK）

投稿時刻は **06:50〜07:10 の範囲**（朝の通勤・起床タイミング）。
TRE通常投稿（18:50〜19:20）とは時間帯が完全に分かれているため、同日に両シリーズを投稿しても問題ない。

## エラー対策

### 「Cannot access a chrome-extension:// URL」が出る場合

→ **Claude in Chrome 以外の拡張機能をすべてオフにする**（2026-05-10 確認済み）

他の拡張機能が干渉してエラーを引き起こすことがある。chrome://extensions で一時的に無効化してから再試行する。

### 途中でつまった場合

→ どの No. まで完了したかを確認し、その番号以降の投稿だけを含む新しいプロンプトを作って再送する。
